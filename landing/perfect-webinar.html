⏱ Minute 22 — The Three Secrets

The three reasons you haven't used GitHub data yet (and why each one collapses).

1

Secret #1 · The Vehicle Belief

“GitHub is too noisy to be a real signal.”

The belief
100 million repos, 99% noise — bots, hackathons, abandoned forks. You’d need a quant team to filter.
The break
We don’t read absolute numbers. We read acceleration vs. baseline. When a company’s engineering velocity deviates sharply from its own 90-day average, that’s not noise — it’s a regime change. Bots don’t sustain regime changes. Hackathons don’t. Hires and product-market-fit do. The math is in the SSRN paper, page 14.
The proof
Across 219 funded rounds, the 14-day commit-velocity ratio above 1.5× preceded the announcement in 7 of 10 cases. Quant funds make billions parsing public SEC filings — same logic, different dataset.

⏱ Minute 48 — The Framework You Run Tomorrow

Here's the whole thing, in seven signals.

You don't need this product to use this framework. You need 35 minutes a week and a cup of coffee. The seven signals from the SSRN paper:

  1. 1. Commit velocity (14d-vs-90d ratio). If a startup's last-14-day commit count is >1.5x its 90-day average, the engineering team is accelerating. The simplest signal.
  2. 2. Contributor diversity (Gini at month -3). Funded rounds had Gini ~0.34. Unfunded had ~0.61. Distributed codebases close more rounds than concentrated ones.
  3. 3. Dependents graph. GitHub exposes every public repo that depends on this org's code. External adoption with no marketing spend = real product-market fit.
  4. 4. README freshness. Substantive README updates in the last 60 days correlate strongly with active fundraising. The README is the public pitch — founders tighten it before the raise.
  5. 5. New repo creation rate. Series A and B startups deploying capital build platform repos — SDKs, CLIs, internal services. Watch for the burst.
  6. 6. Issue-to-PR ratio. 1.5+ is healthy engagement. 0.7 means firefighting. The former gets funded; the latter gets bridged.
  7. 7. Composite score. Weighted blend of the above six. The actual ranking signal you act on.

You can run all seven manually on a single startup in about 35 minutes. You can run them on five startups a week if you set aside a Wednesday afternoon.
