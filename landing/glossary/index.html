Glossary

Clear definitions of terms GitDealFlow uses. Written for investors, no code, no jargon. If a term you're looking for isn't here, tell us.

Deal flow
The pipeline of investment opportunities an investor sees. Strong deal flow means seeing high-quality startups early, before the crowd, the core problem GitDealFlow solves.
Engineering acceleration (Velocity Verdict)
A quantitative signal GitDealFlow computes from public GitHub activity: rising commit velocity, contributor growth, and infrastructure buildout. Not a reference to startup accelerator programs like Y Combinator or Techstars.
Commit velocity
How many code commits a startup's engineering team pushes per week, measured over a rolling window. A sudden sustained increase often precedes a fundraise, the team is scaling the product ahead of the round.
Contributor growth
The rate at which new developers join a startup's GitHub repositories. A spike suggests the team is hiring engineers, which typically follows a fundraising commitment.
Infrastructure buildout
New CI/CD pipelines, deployment configurations, monitoring, and cloud infrastructure appearing in a repo. Signals the company is hardening for scale, a pattern seen before priced rounds.
GitHub momentum
The composite score GitDealFlow computes across commit velocity, contributor growth, and infrastructure buildout. Displayed on the live dashboard as a relative ranking.
Velocity Verdict
GitDealFlow's proprietary signal name. The claim: startups accelerating on GitHub 21-47 days before the round can be identified from public data alone. Validated against 219 documented fundraises.
Leading indicator
Data that changes before the event it predicts. GitDealFlow is a leading indicator for fundraises; Crunchbase and PitchBook are lagging indicators (they record rounds after they're announced).
Signal Digest
The free Sunday email: five startups accelerating on GitHub, each with sector, stage, and a plain-English note on why it's moving. The core free offer.
pSEO (Programmatic SEO)
Pages generated algorithmically at scale, e.g., GitDealFlow's /best/ and /sectors/ pages. Each targets a specific search query with unique, data-backed content.
MCP (Model Context Protocol)
An open protocol that lets AI agents (Claude, Cursor, ChatGPT) discover and use tools. GitDealFlow exposes its deal-flow data through an MCP server so agents can query startup signals directly.
A2A (Agent-to-Agent)
Google's protocol for AI agents to communicate. GitDealFlow's A2A endpoint lets agent orchestrators query deal-flow signals programmatically.
SSRN
Social Science Research Network, an open-access preprint repository. GitDealFlow's methodology is published at SSRN 6606558.
