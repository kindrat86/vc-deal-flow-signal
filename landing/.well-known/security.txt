# Reporting guidelines
# Please email signal@gitdealflow.com with:
#   - A clear description of the issue
#   - Steps to reproduce
#   - Affected URL or endpoint
#   - Your name (or pseudonym) for attribution if desired
#
# We aim to acknowledge reports within 5 business days.
# This is a small independent project — there is no bug bounty,
# but we credit responsible disclosures in our changelog if requested.
#
# Please do NOT publicly disclose vulnerabilities until we have
# acknowledged them and worked with you on a fix.
