Servidor MCP

GitDealFlow, Servidor MCP

Rastrea la aceleración de ingeniería de startups a partir de datos públicos de GitHub. Descubre startups de alto momentum antes de que anuncien financiación.

Cómo funciona la señal: GitDealFlow lee la actividad pública de GitHub de 4.200+ startups y rastrea la velocidad de commits, el crecimiento de contribuidores y la expansión de repositorios. Cuando esas tres aceleran juntas, el equipo se está preparando típicamente para levantar capital. En un panel de investigación de 219 rondas documentadas, la aceleración se adelantó al anuncio público de la ronda en 21-47 días. El email semanal entrega cinco nombres cada domingo, y este servidor MCP expone el mismo dataset a los agentes.

El servidor MCP de GitDealFlow expone el dataset de momentum de startups a cualquier cliente compatible con MCP. Todas las herramientas son de solo lectura, idempotentes y completamente gratuitas: sin autenticación, sin API key, sin límites de tasa. Los datos se derivan de la actividad pública de GitHub de 4.200+ startups, con la metodología publicada en SSRN bajo CC BY 4.0 junto a un dataset abierto.

Inicio rápido (stdio)

Para Claude Desktop, Claude Code, Cursor o cualquier cliente que soporte servidores MCP locales, ejecuta el paquete publicado directamente:

npx -y @gitdealflow/mcp-signal

Transporte HTTP Streamable

Para clientes MCP alojados (ChatGPT apps, runtimes MCP remotos) que prefieren un endpoint URL, usa el servidor HTTP Streamable:

https://signals.gitdealflow.com/api/mcp/rpc

Instalar en Claude Desktop

Añade a claude_desktop_config.json:

{
 "mcpServers": {
   "gitdealflow": {
     "command": "npx",
     "args": ["-y", "@gitdealflow/mcp-signal"]
   }
 }
}

Instalar en Cursor

Añade a .cursor/mcp.json:

{
 "mcpServers": {
   "gitdealflow": {
     "command": "npx",
     "args": ["-y", "@gitdealflow/mcp-signal"]
   }
 }
}

Inspeccionar

npx @modelcontextprotocol/inspector npx -y @gitdealflow/mcp-signal

Herramientas disponibles (6)

  • get_trending_startups: Las 20 startups con mayor aceleración en todos los sectores.
  • search_startups_by_sector: Filtra el universo rastreado por sector (20 slugs sectoriales enumerados).
  • get_startup_signal: Señal de momentum de ingeniería para una startup específica; insensible a mayúsculas y tolerante a la normalización.
  • get_signals_summary: Periodo, frescura y URLs de formato para el dataset de señales actual.
  • get_scout_receipts: Scout Score (0-100) para un usuario de GitHub, calculado a partir de su historial de starring frente a empresas breakout validadas.
  • get_methodology: Texto completo de la metodología y URL canónica, para que cualquier agente pueda verificar cómo se construye la señal.

Otras superficies programáticas

El mismo dataset está disponible sin ningún cliente MCP: API JSON en https://signals.gitdealflow.com/api/signals.json, export CSV en /api/signals.csv, una API de function-calling (/api/agent/tools + /api/agent/call) para SDKs de OpenAI/Anthropic/Gemini, un endpoint A2A en /api/a2a, un endpoint NLWeb en /api/nlweb y una especificación OpenAPI 3.1 completa en /api/openapi.json. Todo gratuito y sin autenticación.
