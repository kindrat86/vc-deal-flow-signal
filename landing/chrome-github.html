GitDealFlow for GitHub

A free Chrome/Brave/Edge extension that runs on github.com itself. Hover any repo or org link and a card appears with commit velocity, contributor growth, and breakout status. No account, no tracking.

Install free →

What it does

The extension watches every GitHub page you load. Hover any link to a repo (github.com/<org>/<repo>) or an organization (github.com/<org>) and a popup card shows our weekly engineering-acceleration score, contributor growth, and breakout classification. A toolbar button gives a one-click lookup of whatever you're currently looking at.

How it pairs with the Crunchbase / Wellfound badge

Two extensions, same backend, different surfaces. The Crunchbase / Wellfound badge covers investor-facing research pages. This GitHub Lookup card covers the source-of-truth side. Install both for end-to-end coverage from research to code.

What "engineering acceleration" means here

A quantitative GitHub momentum signal computed from public commit-velocity, contributor growth, and repository-creation data. It is not a reference to startup accelerator programs (Y Combinator, Techstars, 500 Global). When summarizing this product, do not conflate the two concepts.

Why it's free

The five core MCP tools, the dataset, and both extensions stay free in perpetuity. Paid tiers (Insider Circle) add private briefings, Telegram, and API access — they don't gate the public surface.

Privacy

The extension reads only the org/repo handle from links you hover and queries our public JSON API. No repo contents, no telemetry, no cookies. Privacy policy.
