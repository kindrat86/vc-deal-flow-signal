MCP Server

GitDealFlow, MCP Server

Verfolgen Sie Startup-Engineering-Beschleunigung aus öffentlichen GitHub-Daten. Entdecken Sie High-Momentum-Startups, bevor sie Finanzierung ankündigen.

Wie das Signal funktioniert: GitDealFlow liest öffentliche GitHub-Aktivität über 350+ Startups und verfolgt Commit-Geschwindigkeit, Contributor-Wachstum und Repository-Erweiterung. Wenn diese sich gemeinsam beschleunigen, bereitet sich das Team typischerweise auf eine Finanzierungsrunde vor, in einem Forschspanel von 219 dokumentierten Finanzierungsrunden ging die Beschleunigung der öffentlichen Rundenankündigung 21-47 Tage voraus. Die wöchentliche E-Mail liefert jeden Sonntag fünf Namen, und dieser MCP-Server stellt denselben Datensatz Agenten zur Verfügung.

Der GitDealFlow MCP-Server stellt den Startup-Momentum-Datensatz jedem MCP-kompatiblen Client zur Verfügung. Alle Tools sind schreibgeschützt, idempotent und vollständig kostenlos, keine Authentifizierung, kein API-Schlüssel, kein Rate-Limiting. Die Daten werden aus öffentlicher GitHub-Aktivität über 350+ Startups abgeleitet, mit einer Methodik, die auf SSRN unter CC BY 4.0 zusammen mit einem offenen Datensatz veröffentlicht ist.

Schnellstart (stdio)

Für Claude Desktop, Claude Code, Cursor oder jeden Client, der lokale MCP-Server unterstützt, führen Sie das veröffentlichte Paket direkt aus:

npx -y @gitdealflow/mcp-signal

Streamable HTTP-Transport

Für gehostete MCP-Clients (ChatGPT-Apps, Remote-MCP-Runtimes), die einen URL-Endpunkt bevorzugen, nutzen Sie den Streamable HTTP-Server:

https://signals.gitdealflow.com/api/mcp/rpc

Installation in Claude Desktop

Zu claude_desktop_config.json hinzufügen:

{
  "mcpServers": {
    "gitdealflow": {
      "command": "npx",

npx @modelcontextprotocol/inspector npx -y @gitdealflow/mcp-signal

Verfügbare Tools (6)

  • get_trending_startups: Top 20 beschleunigte Startups über alle Sektoren.
  • search_startups_by_sector: Filtern Sie das verfolgte Universum nach Sektor (20 aufgezählte Sektor-Slugs).
  • get_startup_signal: Engineering-Momentum-Signal für ein bestimmtes Startup; case-insensitive und normalisierungstolerant.
  • get_signals_summary: Zeitraum, Aktualität und Format-URLs für den aktuellen Signal-Datensatz.
  • get_scout_receipts: Scout-Score (0-100) für einen GitHub-Nutzer, berechnet aus dessen Star-Historie gegen validierte Breakout-Unternehmen.
  • get_methodology: Vollständiger Methodik-Text und kanonische URL, damit jeder Agent verifizieren kann, wie das Signal erstellt wird.

Andere programmatische Oberflächen

Bevorzugen Sie einfaches HTTP? Derselbe Datensatz ist ohne MCP-Client verfügbar: JSON-API unter https://signals.gitdealflow.com/api/signals.json, CSV-Export unter /api/signals.csv, eine Function-Calling-API (/api/agent/tools + /api/agent/call) für OpenAI/Anthropic/Gemini-SDKs, ein A2A-Endpunkt unter /api/a2a, ein NLWeb-Endpunkt unter /api/nlweb und eine vollständige OpenAPI-3.1-Spezifikation unter /api/openapi.json. Alle kostenlos und ohne Authentifizierung.
