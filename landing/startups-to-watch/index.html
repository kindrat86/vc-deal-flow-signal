Quarterly rankings of the startups showing the strongest public GitHub engineering acceleration — 20 sectors, updated every quarter since Q3 2025.

How are these rankings built?

Every page is generated from the same public dataset: GitHub commit velocity, contributor growth, and repository expansion across the tracked orgs, aggregated per quarter. No pitch decks, no press releases — only what the engineering teams actually shipped in public. The full method is documented at signals.gitdealflow.com/methodology.
