How to use these datasets

Every dataset in this catalog is published under CC BY 4.0, which means you are free to download, modify, redistribute, and even use commercially, as long as you credit the source. Attribution format: "Source: [Dataset Name], GitDealFlow Portfolio, CC BY 4.0." No API keys, no rate limits, no authentication for CSV and JSON downloads.

Datasets are split across the portfolio's sites but catalogued centrally here. Each card below links to the canonical page for that dataset, where you will find the download link, full field descriptions, update frequency, and sample outputs.

Data format details

All datasets are available in at least one machine-readable format:

  • CSV (text/csv, UTF-8): Standard comma-separated values with header row. Importable into Excel, Google Sheets, Python (pandas), R, or any spreadsheet tool.
  • JSON (application/json): Structured data suitable for API consumption, JavaScript applications, and programmatic processing.
  • JSON-LD / Schema.org Dataset markup: Every dataset page includes structured metadata following the Schema.org Dataset type, making datasets discoverable by Google Dataset Search and AI agents.

Row counts range from 10 (OFAC enforcement actions) to 269 (VC deal flow benchmarks). Update frequencies range from weekly (VC signals, momentum index) to annual (SaaS benchmarks, churn data).
