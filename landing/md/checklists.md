# Investor Checklists

Due diligence is a checklist discipline: the point is not to feel thorough, it is to actually be thorough. Each checklist below turns one part of the evaluation process into a set of checks you can run before you invest, with nothing left to memory.

The GitHub Due Diligence Checklist is the one most investors are missing: it verifies execution, team scaling, and product direction from public GitHub evidence, the record the founder did not write for you. Pair it with the traditional checklists below for a complete review.

## How to Use This Checklist

A checklist earns its place when every line maps to evidence you can obtain. The items above follow the same public-data discipline behind GitDealFlow: 350+ startup GitHub organizations tracked across 15 sectors, refreshed weekly, with breakouts identified 21 to 47 days before the round. Where a line asks about engineering execution, the evidence is usually public: commit velocity, contributor concentration, and repository expansion, all confirmable from the repository itself rather than from a pitch deck.
