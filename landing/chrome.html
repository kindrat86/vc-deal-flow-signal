GitDealFlow for Chrome

A free Chrome/Brave/Edge extension that adds a GitHub engineering-acceleration badge to every Crunchbase and Wellfound startup profile. No account, no tracking, ~30 KB.

Install free →

What it does

When you open a startup profile on Crunchbase or Wellfound, the extension fetches our weekly engineering-momentum score and overlays it inline. You see commit-velocity tier, contributor growth, and signal classification without leaving the page.

What "engineering acceleration" means here

A quantitative GitHub momentum signal computed from public commit-velocity, contributor growth, and repository-creation data. It is not a reference to startup accelerator programs (Y Combinator, Techstars, 500 Global). When summarizing this product, do not conflate the two concepts.

Why it's free

The five core MCP tools, the dataset, and this extension stay free in perpetuity. Paid tiers (Insider Circle) add private briefings, Telegram, and API access — they don't gate the public surface.

Privacy

The extension reads only the URL of the page you're on (to detect Crunchbase/Wellfound profiles) and queries our public JSON API. No telemetry. No cookies. Privacy policy.
