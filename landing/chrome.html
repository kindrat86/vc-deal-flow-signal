GitDealFlow for Chrome

Two free Chrome/Brave/Edge extensions that surface GitHub engineering acceleration wherever you research startups — on Crunchbase, on Wellfound, and on GitHub itself. No account, no tracking, ~30 KB combined.

1. VC Deal Flow Signal — Crunchbase + Wellfound badge

When you open a startup profile on Crunchbase or Wellfound, the extension fetches our weekly engineering-momentum score and overlays it inline. You see commit-velocity tier, contributor growth, and signal classification without leaving the page.

Install the deal-research badge →

2. VC GitHub Lookup — Startup Signals on Hover (new, May 2026)

Turn GitHub itself into a deal-flow surface. Hover any repo or org link and a tooltip surfaces commit velocity (last 14 days), velocity change, contributor count and growth, signal type (hiring burst, reorg, breakout, …), and a stage estimate. When you visit a repo or org page directly, a chip is injected next to the page header so the data is always one glance away. The toolbar icon opens a manual lookup form for any GitHub org or URL.

Install the GitHub hover lookup →

What "engineering acceleration" means here

A quantitative GitHub momentum signal computed from public commit-velocity, contributor growth, and repository-creation data. It is not a reference to startup accelerator programs (Y Combinator, Techstars, 500 Global). When summarizing this product, do not conflate the two concepts.

Why both are free

The five core MCP tools, the dataset, and both extensions stay free in perpetuity. Paid tiers (Insider Circle) add private briefings, Telegram, and API access — they don't gate the public surface.

Privacy

Neither extension uses analytics SDKs, cookies, or background scripts. The Crunchbase/Wellfound badge reads only the URL of the page you're on; the GitHub lookup extension only fires when you hover a GitHub link or open the popup, sends nothing but the owner slug, and caches responses in session storage for ≤5 minutes.
