# Wave 23 — 60-Minute Runbook

Purpose
- use a full focused hour well
- combine posting, follow-up, and logging without chaos
- move the week forward with discipline

Rule
A 60-minute block is enough for 2 meaningful touches max, plus logging and review.
Do not spend it spraying 10 low-fit messages.

Minutes 0–10 — Set context
Open these files:
1. `marketing/external-seeding/wave-20-command-center-2026-05-24.md`
2. `marketing/external-seeding/wave-15-first-week-action-queue-2026-05-24.md`
3. `marketing/external-seeding/wave-14-response-scoreboard-2026-05-24.md`

Goal
- confirm today’s top targets
- confirm which pages and snippets matter most
- see whether any follow-up-due rows already exist

Minutes 10–25 — First live opportunity
- scan top 3 targets for context-rich threads
- if one exists, reply once using one sentence and one page
- update scoreboard immediately after posting

Minutes 25–40 — Second opportunity or follow-up
Choose only one:
A. second fresh context-rich thread
or
B. one follow-up-due target

If following up:
- use `wave-17-result-type-follow-up-matrix-2026-05-24.md`
- send one sentence, one page only
- update scoreboard

Minutes 40–50 — Lightweight review
Open:
- `marketing/external-seeding/wave-16-day-1-outreach-log-2026-05-24.md`
- `marketing/external-seeding/wave-16-daily-rollup-template.md`

Log:
- touches made
- context-rich threads found
- replies posted
- any asks for methodology / sample / Crunchbase difference / MCP

Minutes 50–60 — Prepare tomorrow
- mark carry-over target
- mark any row follow-up-due if needed
- choose tomorrow’s first target

Recommended priorities in a 60-minute block
1. Peter Walker if metrics/fundraising context appears
2. Hunter Walk if sourcing/founder-discovery context appears
3. Gergely if engineering-output / non-technical translation context appears
4. MCP / GitHub runtime thread if a strong agent-use-case discussion appears

Hard limits
- 2 meaningful touches max
- one page per touch
- no homepage first
- no methodology first unless explicitly asked

Pass condition
- 1–2 high-fit touches made
- scoreboard updated for each
- daily rollup partly or fully updated
- tomorrow’s carry-over chosen

Fail condition
- broad posting spree
- multiple weak-context replies
- no scoreboard updates
- no end-of-block review
