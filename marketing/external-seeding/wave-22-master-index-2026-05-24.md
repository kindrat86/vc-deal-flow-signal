# Wave 22 Master Index — External Seeding System

Purpose
- make every outreach asset easy to find in seconds
- group the system by job, not by wave number
- give one clean starting point for any operator working the stack

Root folder
- `marketing/external-seeding/`

Core rule
Do not hunt for files.
Start here, pick the job, open the one best asset, then work.

========================================
1. Start here by situation
========================================

If you need to:
- choose the right page to send -> go to "Cheat Sheets"
- choose the right snippet for a platform -> go to "Cheat Sheets"
- decide whether to send at all -> go to "Cheat Sheets"
- know today’s top targets -> go to "Execution"
- send the first outreach this week -> go to "Execution"
- respond after someone replies -> go to "Follow-Up and Escalation"
- log outcomes -> go to "Tracking and Review"
- practice before posting -> go to "Simulation and QA"
