First 5 minutes
1. Open:
   - `marketing/external-seeding/wave-17-tier1-rapid-response-pack-2026-05-24.md`
   - `marketing/external-seeding/wave-14-response-scoreboard-2026-05-24.md`

2. Copy thread URL immediately into the scoreboard.
3. Change status -> escalated.
4. Identify the actual mention type:
   - timing / sourcing
   - technical signal
   - methodology / rigor
   - sample / output
   - MCP / AI / agents

Minutes 5–10 — Choose the one page
If the mention is about:

Minutes 10–15 — Draft the reply
Pattern
- acknowledge their exact point
- add one useful extension or one data point
- include one proof page only if needed

Examples
If timing-related:
Useful framing. The part we keep seeing too is that most tools help with verification, while the harder problem is noticing what changed before the story gets crowded.
https://signals.gitdealflow.com/answers/deal-flow-timing-vs-verification

If technical-signal-related:
The narrower claim is not “GitHub predicts everything.” It’s that patterns in public engineering behavior can become visible before the public story catches up.
https://signals.gitdealflow.com/answers/what-is-startup-engineering-momentum

If methodology-related:
Best starting point is the methodology itself:
https://signals.gitdealflow.com/methodology

If output-related:
Best proof is the sample output:
https://gitdealflow.com/report

If MCP-related:
Useful MCP question: can your agent query real startup signal data without private API friction?
https://signals.gitdealflow.com/integrations/best-mcp-server-for-vc-research

Minutes 15–20 — Post and log
After posting:
- update scoreboard row with status / result / snippet / URL
- note exact page sent
- if they reply, switch to replied immediately
- if collaboration or intro appears, note escalated follow-up

Do not do
- no 3-link follow-up
- no homepage first
- no product-tour response
- no “we built a tool” opener if the distinction itself works
- no argument spiral

Pass condition
- one context-fit response sent inside the 4h SLA
- one exact proof page chosen
- scoreboard updated immediately

Fail condition
- slow response
- multiple links
- defensive tone
- no logging
