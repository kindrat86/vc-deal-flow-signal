# Wave 25 Operator Handoff Note — External Seeding System

What this system is
- a full operating system for external seeding and outreach around GitDealFlow / VC Deal Flow Signal
- designed to remove improvisation in page choice, snippet choice, follow-up, escalation, and review

What this system is not
- an autoposter
- a replacement for judgment about live context
- a reason to post without a real thread or real audience fit

Where to start
1. Read `wave-24-master-operator-runbook-2026-05-24.md`
2. If today is a live execution day, open `wave-21-first-live-week-activation-2026-05-24.md`
3. If you need fast page choice, open `wave-18-best-page-by-question-cheatsheet-2026-05-24.md`
4. If you need fast snippet choice, open `wave-18-best-snippet-by-platform-cheatsheet-2026-05-24.md`
5. Log every action in `wave-14-response-scoreboard-2026-05-24.md`

Best defaults
- investor context -> timing vs verification page
- technical context -> startup engineering momentum page
- skeptical context -> sample report or methodology
- agent context -> MCP VC research page

How to know if you are using the system correctly
- you send one sentence and one page
- you only post in live context
- you log immediately after action
- you can explain why you chose that page instead of another page
- you can state the next follow-up page before you post

How to know if you are using it badly
- you open many files before acting
- you paste 3+ links in first touch
- you send homepage first by habit
- you argue with skeptics instead of narrowing the claim
- you forget to update the scoreboard

What to patch only after live use
- any page that repeatedly fails to convert curiosity into a better next question
- any snippet that repeatedly feels too long or too abstract
- any platform-specific play that keeps drawing the wrong type of response

Final rule
The system wins by reducing noise, not by increasing output.
If there is no real context, do nothing.
If there is real context, send one clean line, one clean page, then log it.
