# Wave 19 Dry-Run Scoring Rubric — 2026-05-24

Purpose
- give a simple pass/fail framework for future outreach simulations
- help Maryan or Sipi review whether the chosen move matches the system

Score each dry run from 0 to 10.

## Scoring categories

1. Context match (0-2)
- 0 = no real context, forced send
- 1 = partial fit, context exists but question is muddy
- 2 = clear live context and relevant thread

2. Page choice (0-2)
- 0 = wrong page entirely
- 1 = usable but not the cleanest page
- 2 = exact page for the exact question

3. Snippet quality (0-2)
- 0 = pitchy, vague, or too long
- 1 = okay but not sharp
- 2 = one clean distinction or one useful data-shaped line

4. Link discipline (0-2)
- 0 = too many links / link dump
- 1 = one good link plus unnecessary extra context
- 2 = one link only, clearly the proof for the sentence

5. Follow-up logic (0-2)
- 0 = no follow-up logic or wrong follow-up
- 1 = follow-up exists but is not the cleanest next move
- 2 = exact next page and reply path chosen correctly

## Score interpretation
- 9-10 = ready to use live
- 7-8 = usable, but tighten wording
- 5-6 = mixed, revisit page or snippet choice
- 0-4 = do not send, re-run the decision tree

## Quick pass/fail shortcut

Immediate fail if any of these happen:
- more than one core link in the first touch
- homepage sent by default when a sharper page exists
- methodology sent when the person asked for practical output
- sample report sent when the person asked for formal rigor
- product-tour language used in a context thread

Immediate pass if all are true:
- one clear question identified
- one exact page chosen
- one sentence used
- one proof link only
- follow-up path already known

## Review note
The point of the rubric is not academic scoring.
It is to make sure the system stays disciplined when real posting starts.
