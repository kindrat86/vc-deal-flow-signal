## Fast tagging guide

Use these tags in notes if helpful:
- [TV] timing vs verification
- [SEM] startup engineering momentum
- [GHA] GitHub signals for angels
- [GDF] GitHub deal flow for investors
- [ALT] alternative data tools for angels
- [CBA] Crunchbase alternative
- [MCP] best MCP server for VC research
- [REPORT] sample Sunday watchlist
- [METH] methodology

## Decision rules

- If the person asks for proof, send METH or REPORT.
- If the person asks for differentiation, send TV or CBA.
- If the person is technical, send SEM or MCP.
- If the person is investor/media, send TV or ALT.
- If there is no relevant live context, do not post just to “tick the box.”
