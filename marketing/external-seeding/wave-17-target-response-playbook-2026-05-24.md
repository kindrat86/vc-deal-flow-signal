# Wave 17 Target Response Playbook — 2026-05-24

Purpose
- define what to do the moment a target responds
- prevent overexplaining or wasting a live signal
- keep every follow-up short, useful, and outcome-oriented

Core rule
A response is not a cue to explain everything.
A response is a cue to route the person to the next clean proof page.

Response ladder
1. acknowledge the exact point they made
2. add one useful clarification or one data point
3. send one proof page only if needed
4. end before it turns into a pitch

Never do
- send 3+ links at once
- switch into product-tour mode
- paste the methodology unless they asked for it
- turn a curious reply into a hard sell
