========================================
Quick drill questions
========================================

Before sending anything, ask:
1. Is there real context here?
2. What is the exact question?
3. Which page answers that exact question best?
4. Can I answer in one sentence?
5. Do I need a link at all?

If you cannot answer 1-3 fast
- do not send yet

========================================
Pass / fail standard
========================================

Pass
- one page
- one sharp sentence
- exact context match
- no oversell

Fail
- multiple links in first touch
- homepage sent by default
- methodology sent when they asked for practical output
- product-tour language in a context thread
