G. Hard do-not-send list
========================================

Do not send:
- homepage first to skeptical technical people
- pricing page first to cold media
- long dream-customer explanations
- “we built a tool” as the opener if a sharper distinction works
- more than one core link in the first touch

Best first-link rule
- if the person is investor-facing: send timing vs verification or alt-data comparison
- if the person is technical: send startup engineering momentum or MCP VC research
- if the person is skeptical: send methodology or sample report
