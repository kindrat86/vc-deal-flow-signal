## Fast routing rules

If the reply is:
- “what does it actually look like?” -> second page = REPORT
- “what’s the methodology?” -> second page = METH
- “how is this different from Crunchbase / PitchBook / databases?” -> second page = TV or CBA
- “I’m not technical” -> second page = GHA
- “can an agent use this directly?” -> second page = MCP
