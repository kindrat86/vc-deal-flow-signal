## Note on autonomous following

This list is **follow-ready**, but the follow action itself must be performed
where an authenticated X session exists. This repo's existing X automation runs
via **Chrome MCP on the operator's local machine** (`monitoring/dream-customers/`,
which *reads* tweets/engagement) — there is **no X write-API** wired in, and the
remote CI/agent environment cannot follow accounts. Do the follows from the
logged-in browser, then move each card to "Followed" in the Dream Customers CRM.
