## The Signal

Akto is the open-source API security testing platform. Think Burp Suite or OWASP ZAP, rebuilt from the ground up for modern API-first stacks: REST, GraphQL, gRPC, and the kind of microservice graphs that older scanners simply cannot map. Y Combinator backed it in W22. It has been one of the quietest fast-growers in the cybersecurity portfolio.

This week, Akto's GitHub org registered a +75% commit velocity change with 267 commits over 14 days and 53 distinct contributors active. The signal type is "Framework migration," which in GitDealFlow's taxonomy means the team is overhauling core internals — refactoring the foundations on which everything else sits, usually before something significant ships on top.

**Why this matters for investors.** Framework migration spikes at Growth stage are an important leading indicator. They almost never happen casually. Engineering teams at this stage do not refactor the core unless one of three things is coming: a new product surface that the old core could not support, an enterprise tier that demands a different runtime profile, or a fundraising round where the demo has to clear a higher bar.

**Competitive context.** Salt Security raised more than $300M and has been struggling through layoffs and exec turnover. Noname Security got acquired by Akamai for around $500M. Wallarm is enterprise-only. The open-source, developer-first slot in API security is open, and it is the slot Akto has been quietly building toward since 2022.
