## Weekly content cycle (2 hours total)

### Monday: Write the anchor piece (30 min)
Pick the most interesting signal from the weekly data refresh. Write a 300-word "Signal of the Week" analysis in Data Nerd voice.

Structure:
1. The startup and what they do (1 sentence)
2. The data: commit velocity, contributor growth, signal type (2-3 sentences with specific numbers)
3. Why this matters for investors (1-2 sentences)
4. What could be happening (speculation, with honest uncertainty)

Save to: `marketing/weekly-signals/YYYY-MM-DD-signal.md`

### Monday: Distribute the anchor (30 min)

From that one piece, create:

| # | Format | Platform | Adaptation |
|---|--------|----------|------------|
| 1 | Telegram post | Free community | Full signal + discussion prompt |
| 2 | Twitter/X thread | @data_nerd | Thread: hook tweet (the data point) + 3-4 context tweets + CTA tweet |
| 3 | LinkedIn post | Personal profile | Slightly longer, more professional tone, same data |
| 4 | Reddit comment/post | r/venturecapital | Frame as discussion, not promotion: "Interesting pattern I noticed..." |

## Twitter/X thread template

**Tweet 1 (hook):**
[Startup name]'s commit velocity spiked [X]% in 14 days.

[X] new contributors. [Signal type detected].

Something is happening in [sector]. Here's what the data shows:

**Tweet 2 (context):**
We track GitHub engineering activity across thousands of startup orgs.

When a company's velocity deviates sharply from its own baseline, we flag it.

This pattern has preceded fundraise announcements by 3-6 weeks in our analysis.

**Tweet 3 (the data):**
Here's what [startup] looks like right now:
- Commits (14d): [number] ([change]%)
- Contributors: [number] ([growth]%)
- New repos: [number]
- Signal type: [type]

**Tweet 4 (so what):**
Is it a fundraise? A product launch? A major hire push?

The signal doesn't tell you which. But it tells you something changed, weeks before any announcement.

**Tweet 5 (CTA):**

Free community: [Telegram link]
