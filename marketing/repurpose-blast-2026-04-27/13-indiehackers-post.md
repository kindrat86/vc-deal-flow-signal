# Variant 13 — IndieHackers Short Discussion Post

**Title:** Signal of the Week: framework migration is the underrated VC signal

**Category:** Growth / Metrics

---

This week's most interesting data point from running GitDealFlow:

Akto (open-source API security testing, Y Combinator W22) registered a +75% commit velocity change over 14 days. 267 commits from 53 contributors. Signal type: framework migration.

That signal type is the one most frameworks miss. Deploy-frequency spikes are easy to count. Framework migration is quieter, but it tells you something different: the team is rebuilding the core, which Growth-stage teams almost never do casually.

In our dataset, that pattern is one of the more reliable precursors to a new product surface, an enterprise tier, or a fundraise demo. Historical lag between detection and the public announcement is 3 to 6 weeks.

Context that makes Akto particularly interesting: Salt Security has been working through layoffs and exec turnover. Noname Security was acquired by Akamai in 2024 for around $500M. Wallarm is enterprise-only. The OSS, developer-first slot in API security is open.

We have been tracking 4,200+ startup GitHub orgs for six months and this is one of the cleaner Growth-stage signals we have seen this quarter.

If you are building tools in the VC/angel space or working on alt-data sources for early-stage investing, curious if anyone else is tracking framework-migration signals separately from raw commit counts.
