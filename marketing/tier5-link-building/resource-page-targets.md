## Rule-of-thumb

A resource page is worth pitching if:
1. It's an editorially-maintained list (not user-generated directory) — higher trust
2. It has existing VC / alt-data / scouting / DD content → editorial fit
3. Last-updated within 12 months (stale pages get deprioritized by Google → lower link juice)
4. DA ≥ 40 per Ahrefs/MOZ, OR is authoritative in niche regardless of DA

## Outreach hygiene

- **Do not** send the same template to 3+ pages on the same day (spam filter signal)
- **Do not** CC / BCC between targets
- **Do** personalize first 2 sentences using the specific post title / author name
- **Do** use `Mailmeteor` or similar for mail-merge only if each template is ≥70% customized
- Track in Google Sheet: Date sent, URL, contact, template used, reply Y/N, link placed Y/N, DA
- Kill chain after 1 follow-up — never send a third email
