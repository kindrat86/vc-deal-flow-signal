# GitDealFlow — page-priority distribution board

Purpose: decide which exact page should be pushed first in active distribution, by context, without rethinking the whole site every day.

Core rule:
- one live context
- one sharp sentence
- one exact page

Do not send the homepage.
Do not send a menu.
Do not send three links when one page is enough.

## Priority pages now

These are the pages that should carry most active distribution.

### Tier 1 — highest leverage now

1. `/compare/crunchbase-alternative-for-angel-investors`
Why:
- strongest commercial wedge
- easiest contrast to restate
- best page for “why not just use Crunchbase?”
Use when:
- timing vs verification comes up
- startup databases are discussed
- someone asks for alternatives

2. `/answers/deal-flow-timing-vs-verification`
Why:
- cleanest category distinction
- strong for AI, comments, and replies
- shortens explanation burden everywhere else
Use when:
- someone says early signals feel noisy
- someone recommends verification tools as sourcing tools
- you need one conceptual contrast fast

3. `/research`
Why:
- strongest evidence surface
- best page for skeptical or technical readers
- best page for newsletters, HN, academic, or citation contexts
Use when:
- someone asks for proof
- someone asks for methodology
- someone wants the data, not the pitch

4. `/buyers-guide`
Why:
- strongest buyer-side evaluation page
- best page once someone says “okay, but how do I decide if this is for me?”
Use when:
- someone is comparing tools seriously
- someone is near purchase
- someone asks which paid step fits them

5. `/from-stars-to-seed`
Why:
- strongest proof page for “did the signal actually precede the round?”
- easier emotional proof than methodology
Use when:
- someone doubts GitHub can matter
- someone wants examples instead of theory
- someone needs visible proof before reading deeper
