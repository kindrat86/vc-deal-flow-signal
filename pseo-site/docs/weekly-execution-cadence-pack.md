# GitDealFlow, weekly execution cadence pack

Purpose: define the minimum weekly rhythm so distribution stays alive without rethinking the system from zero.

## Monday
Use:
- `docs/monday-execution-pack.md`

Monday job:
- choose one page to push
- choose one patch candidate
- make the first 3 touches
- log everything same day

Best default pages:
1. `/compare/crunchbase-alternative-for-angel-investors`
2. `/answers/deal-flow-timing-vs-verification`
3. `/research`

## Tuesday to Thursday
Use:
- `docs/direct-engagement-message-pack.md`
- `docs/first-20-direct-engagement-targets.md`
- `docs/distribution-scoreboard-2026-05-26.csv`

Midweek job:
- 1-2 meaningful touches per day
- no homepage links
- one page only per touch
- classify replies fast
- send one next page only

## Friday
Use:
- `docs/friday-learning-pack.md`

Friday job:
- choose one page-angle-platform combination to stop
- choose one page to patch next week
- choose one page to push harder next week
- identify best response type of the week

- Monday decide
- midweek engage
- Friday learn
- next week patch only what reality exposed.
