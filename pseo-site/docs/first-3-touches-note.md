# GitDealFlow — first 3 touches note

Purpose: remove hesitation and define the first three real touches to make from the new distribution stack.

Rule:
- do these before you optimize anything else
- log them the same day
- judge the page-angle fit, not just whether someone replies

## Touch 1
Target:
- live X investor thread discussing Crunchbase, PitchBook, or startup databases
Page:
- `/compare/crunchbase-alternative-for-angel-investors`
Message:
- Crunchbase helps you verify. It usually does not help you notice earlier. That timing gap is the real sourcing problem: https://signals.gitdealflow.com/compare/crunchbase-alternative-for-angel-investors
If they reply, send:
- `/buyers-guide`
Why this is first:
- strongest wedge
- easiest to explain in one sentence
- highest commercial relevance

## Touch 2
Target:
- live Reddit thread asking how angels find startups earlier
Page:
- `/answers/how-angel-investors-use-github-signals`
Message:
- One underrated source is public engineering activity, but only if you treat it as a timing signal rather than a complete diligence layer. This explains the workflow cleanly: https://signals.gitdealflow.com/answers/how-angel-investors-use-github-signals
If they reply, send:
- `/buyers-guide`
Why this is second:
- practical workflow angle
- easier trust than broad product explanation
- good fit for comment-side distribution

## Touch 3
Target:
- newsletter writer or LinkedIn post discussing proof / methodology / real evidence
Page:
- `/research`
Message:
- We published the panel instead of only describing the thesis: 55 venture-backed startups, 219 observations, public methodology. https://signals.gitdealflow.com/research
If they reply, send:
- `/buyers-guide`
Why this is third:
- strongest evidence page
- best for skeptical or technical readers

## Logging rule

Log each touch in the scoreboard immediately.
Use either:
- `docs/distribution-scoreboard.csv`
or
- `docs/distribution-scoreboard-2026-05-26.csv`

## What success looks like

Good result:
- at least one of the three touches triggers a specific follow-up ask
- at least one page clearly feels easier to send than the others
- you learn which route is strongest:
  - wedge
  - workflow
  - evidence

Bad result:
- you send all three as generic product promotion
- you send multiple links in the first touch
- you delay logging and lose the learning loop

## Command

Do these three touches first.
They are the fastest way to discover which page-angle pair is most alive in the market right now.
