# GitDealFlow — 7-day active distribution plan

Purpose: turn the strongest pages into real conversations, not just indexed assets.

Operating rule:
- 1 page focus per day
- 1 primary channel
- 1 backup channel
- 1 exact angle
- 1 exact next page if someone bites

## Daily logging rule

After each touch, update the scoreboard:
- docs/distribution-scoreboard.csv

Fields to update:
- date
- target
- platform
- context
- page_sent
- snippet_used
- thread_or_url
- status
- result
- follow_up_page
- follow_up_due
- next_move
- notes
- response_type

## Minimum daily output

A good day is:
- 1 meaningful public touch
- 1 logged row
- 1 clear next page ready if someone replies

## What not to do this week

- no homepage links
- no product-tour paragraphs
- no multi-link first touches
- no pricing links in first touch unless the buyer is already asking what to buy

## End-of-week review

Answer these:
- which page got the best response?
- which page got ignored?
- which channel matched best?
- which snippet felt easiest to send?
- which second-step page got requested most?
- which page should be patched before the next wave?

## Command

This week is not about volume.
It is about proving which exact page-angle-channel combinations produce real conversations.
