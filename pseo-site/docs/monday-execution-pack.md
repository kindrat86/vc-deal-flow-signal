# GitDealFlow — Monday execution pack

Purpose: tell you exactly what to do first when the week starts, without rethinking the system from scratch.

Use this on Monday morning before doing any new SEO work.

Date created: 2026-05-24
Owner: Sipi

## The Monday objective

Do three things in this order:
1. measure what moved
2. decide which page deserves pressure this week
3. execute the first 1–3 touches with the right page, not the homepage

## Monday order of operations

### Block 1 — measurement first
Open these files first:
- `docs/seo-command-center.md`
- `docs/gsc-measurement-template.csv`
- `docs/top10-weekly-page-tracker.csv`
- `docs/second-step-page-tracker.csv`
- `docs/distribution-scoreboard.csv`

Then collect for the primary 5 pages:
- /research
- /compare/crunchbase-alternative-for-angel-investors
- /weekly/top-100
- /from-stars-to-seed
- /answers/how-angel-investors-use-github-signals

Metrics to fill:
- impressions
- clicks
- CTR
- avg position
- indexed status
- distribution touches from last week

## Monday decision rule

After measurement, choose one of these three modes:

### Mode A — authority mode
Choose this if:
- /research gained traction
- proof/rigor questions increased
- commercial pages still lag behind proof pages

Primary page for the week:
- /research

Support pages:
- /methodology
- /from-stars-to-seed

### Mode B — commercial mode
Choose this if:
- compare/answers pages are getting impressions but weak clicks
- people ask how GitDealFlow differs from Crunchbase or PitchBook
- tool-choice conversations are active

Primary page for the week:
- /compare/crunchbase-alternative-for-angel-investors

Support pages:
- /answers/deal-flow-timing-vs-verification
- /buyers-guide

### Mode C — freshness mode
Choose this if:
- /weekly/top-100 gets the most real interest
- social/distribution contexts are asking “what’s moving now?”
- repeat-visit logic seems strongest

Primary page for the week:
- /weekly/top-100

Support pages:
- /research
- /receipts
- /firstlook

## Monday touch plan

After choosing the weekly primary page:
- do 1 X touch
- do 1 Reddit touch
- do 1 LinkedIn touch

Default first three touches if you need a clean start:
- X timing wedge -> `/compare/crunchbase-alternative-for-angel-investors`
- Reddit workflow angle -> `/answers/how-angel-investors-use-github-signals`
- newsletter / LinkedIn proof angle -> `/research`

Use:
- `docs/first-3-touches-note.md`
- `docs/direct-engagement-message-pack.md`
- `docs/first-20-direct-engagement-targets.md`

No more than 3 meaningful touches unless a reply creates a clear follow-up.

## Monday follow-up rule

If a response comes in, classify it using:
- `docs/distribution-response-taxonomy-2026-05-26.md`

Then route using:
- `docs/follow-up-routing-map.md`
- `docs/live-response-playbook.md`

Do not improvise a menu.
Send one exact next page.

## Monday review questions

Ask these before doing anything new:
- Which page got the best response last week?
- Which page got ignored repeatedly?
- Which second-step page got requested most?
- Which shard looks heavy without enough return?
- Which route is strongest for trust?
- Which route is strongest for commercial intent?

## Monday output you want by the end of the first hour

You should know:
- this week’s primary page
- this week’s primary patch page (if any)
- this week’s top 3 touches
- which second-step page to watch

## Do not do on Monday

- do not split more sitemaps
- do not start new content clusters
- do not patch 5 pages at once
- do not distribute homepage first
- do not touch low-value long-tail inventory before looking at the top 5 pages

## Best default if the data is ambiguous

If measurement is weak or inconclusive, default to:
1. push /research
2. use /compare/crunchbase-alternative-for-angel-investors as the commercial wedge
3. use /weekly/top-100 as the freshness layer

That trio is still the strongest weekly operating set.
