VC Deal Flow Signal API Docs

All surfaces are free, public, require no authentication, and never will. Data refreshed weekly (Mondays ~09:00 UTC).

JSON API

Get trending startups

GET https://signals.gitdealflow.com/api/signals.json

Returns the full dataset: 324+ startups across 20 sectors, ranked by commit velocity. Each entry includes velocity, contributors, signal type, stage, geography.

curl https://signals.gitdealflow.com/api/signals.json | jq '.sectors[0].periods[0].startups[:3]'
MCP Server

Model Context Protocol — 6 tools

Use with Claude Desktop, Claude Code, Cursor, or any MCP host:

npx -y @gitdealflow/mcp-signal

Or via HTTP (Streamable HTTP):

POST https://signals.gitdealflow.com/api/mcp/rpc

Available tools

  • get_trending_startups — top 20 across all sectors
  • search_startups_by_sector(sector) — sector slug from 20 values
  • get_startup_signal(name) — case-insensitive, normalization-tolerant
  • get_signals_summary — period, freshness, format URLs
  • get_scout_receipts(github_username) — Scout Score (0–100) from starring history
  • get_methodology — full methodology text + canonical URL

npm: @gitdealflow/mcp-signal · MCP discovery manifest

CSV Export

Bulk data for spreadsheets & dataframes

GET https://signals.gitdealflow.com/api/signals.csv

Each row: name, sector, commit_velocity_14d, commit_velocity_change, contributors, signal_type, stage, geography, description.

OpenAPI 3.1 Spec

Standard API specification

GET https://signals.gitdealflow.com/api/openapi.json

Full OpenAPI 3.1 specification compatible with Swagger, Postman, and code generators.

A2A Protocol

Agent-to-Agent JSON-RPC 2.0

POST https://signals.gitdealflow.com/api/a2a
Content-Type: application/json

{"jsonrpc":"2.0","method":"skills/get_trending_startups","id":"1"}

Supports all 6 tools via A2A skills. AgentCard at /.well-known/agent-card.json

NLWeb

Natural-language query endpoint (for Bing Copilot)

POST https://signals.gitdealflow.com/api/nlweb
Content-Type: application/json

{"query": "trending fintech startups this week"}

Returns schema.org-typed JSON-LD. Supports: trending, sector startups, startup info, methodology, dataset queries.

Scout Score

Compute a VC Scout Score for any GitHub user

GET https://signals.gitdealflow.com/api/receipts/{username}

Returns score (0–100), rank (curious/scout/sharp/elite/oracle), star count, matched unicorns, early calls, personality, share URL.

curl https://signals.gitdealflow.com/api/receipts/sindresorhus | jq '.score, .rank, .personality'

GitHub README badge:

[![VC Scout Score](https://signals.gitdealflow.com/api/badge/scout/{username}.svg)](https://signals.gitdealflow.com/scout?ref=gh-readme)
Startup Badge

Embed a startup's engineering momentum badge

GET https://signals.gitdealflow.com/api/badge/{startup-name}

Returns an SVG badge showing signal type + commit velocity for any tracked startup.

curl https://signals.gitdealflow.com/api/badge/posthog
OG Images

Dynamic Open Graph images for social sharing

GET https://signals.gitdealflow.com/api/og/receipts/{username}

Returns a 1200×630 PNG image with the user's Scout Score, rank, and top wins — perfect for X/Twitter card previews.

GET https://signals.gitdealflow.com/api/og/signal-card?org=PostHog&metric=Velocity&delta=%2B142%25
