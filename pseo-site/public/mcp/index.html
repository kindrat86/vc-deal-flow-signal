Connect any MCP-compatible AI agent to the VC Deal Flow Signal dataset — 324+ venture-backed startups tracked across 20 sectors, updated weekly.

Available Tools

  • get_trending_startups — Top 20 startups across all sectors ranked by momentum

    Returns: name, description, stage, commit velocity, contributor growth, sector

  • search_startups_by_sector — Sector-specific startup signals

    Parameter: sector ∈ ai-ml, fintech, cybersecurity, developer-tools, healthcare, climate-tech, enterprise-saas, data-infrastructure, web3, robotics, edtech, ecommerce-infrastructure, supply-chain, legal-tech, hr-tech, proptech, agtech, gaming, space-tech, social-community

  • get_startup_signal — Signal for a specific startup by name

    Parameter: name — case-insensitive, normalization-tolerant

  • get_signals_summary — Current period metadata and format URLs
  • get_scout_receipts — Scout Score (0–100) from GitHub starring history

    Parameter: github_username

  • get_methodology — Full methodology text + canonical URL

ChatGPT (Streamable HTTP)

POST https://signals.gitdealflow.com/api/mcp/rpc
Content-Type: application/json

{"jsonrpc": "2.0", "method": "tools/list", "id": 1}

Direct HTTP (any agent)

# List tools
curl -X POST https://signals.gitdealflow.com/api/mcp/rpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "tools/list", "id": 1}'

# Get trending startups
curl -X POST https://signals.gitdealflow.com/api/mcp/rpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "tools/call", "params": {"name": "get_trending_startups", "arguments": {}}, "id": 2}'
