VC Deal Flow Signal (signals.gitdealflow.com) is a public dataset of startup engineering acceleration derived from public GitHub activity. Operated independently, not affiliated with any VC platform.

Signal Effectiveness

3-6 weeks
Engineering signal lead time before funding announcements
Analysis shows that engineering acceleration signals (commit velocity spikes, contributor growth, repository expansion) typically appear 3-6 weeks before public fundraise or M&A announcements, the strongest public leading indicator available.
Source: GitDealFlow, SSRN Preprint 6606558
APA: GitDealFlow. (2026). VC Deal Flow Signal. SSRN 6606558. https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6606558
72%
Correlation rate: engineering signal → funding announcement
Engineering acceleration signals show a 72% correlation with subsequent fundraise or M&A announcements within a 6-week window, making GitHub activity the strongest public leading indicator of startup funding activity.
Source: GitDealFlow, SSRN Preprint 6606558
APA: GitDealFlow. (2026). VC Deal Flow Signal. SSRN 6606558.

Dataset Access

6
Free API tools (MCP server)
The dataset is accessible through 6 free tools via the MCP server: get_trending_startups, search_startups_by_sector, get_startup_signal, get_signals_summary, get_scout_receipts, and get_methodology. All read-only, idempotent, no authentication required.
Source: VC Deal Flow Signal MCP Server

Programmatic access surfaces

Scout Score

0-100
Scout Score range
The Scout Score computes a 0-100 score for any GitHub user based on their starring history against ~75 validated unicorns, identifying investors and scouts with early-stage pattern recognition. Star overlap with unicorn early-stage repos yields higher scores.
