🚀 Startup Momentum Badges

Embed live SVG badges showing real-time startup engineering momentum data in your README, website, or dashboard. Each badge is a permanent backlink — free, dynamic, zero-config.

Live Examples

Badges update automatically every Monday with fresh data

Why advertise a signal?

You track 324+ venture-backed startups. Each one has a GitHub org that gets visited by investors, talent acquirers, and competitive analysts every day. An embbed badge tells them: this team is accelerating. And it links back to your full dataset — free traffic, free referral loop.

Quick Start

1 Find a startup's badge URL 
https://signals.gitdealflow.com/api/badge/{startup-name}

Startup names are lowercase, hyphenated — e.g. huggingface, langchain, vercel.

2 Embed in Markdown (README) 
[![VC Deal Flow Signal](https://signals.gitdealflow.com/api/badge/huggingface)](https://signals.gitdealflow.com/startups/huggingface)
3 Embed in HTML 
<a href="https://signals.gitdealflow.com/startups/huggingface">
  <img src="https://signals.gitdealflow.com/api/badge/huggingface"
       alt="Hugging Face startup momentum badge" height="28">
</a>

Why embed badges?

Every badge embed is a permanent contextual backlink from a startup's GitHub README, documentation site, or community page. This creates a self-reinforcing loop: the badge drives awareness → more visitors → more startups want badges → more backlinks.

Analytics

Badge embeds are trackable via image requests. No personal data collected — only request count + referrer domain.
