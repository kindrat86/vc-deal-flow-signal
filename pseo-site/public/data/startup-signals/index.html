Dataset Details

Complete ranked dataset of 324+ venture-backed startups tracked by engineering momentum signals in Q3 2026. Each entry includes commit velocity (14-day rolling window), commit velocity change (percent change vs prior window), contributor count and growth rate, new repository count, signal type classification (framework migration, engineering hiring burst, deploy frequency spike, infrastructure buildout), stage, geography, and GitHub profile URL. Sectors covered: Web3, EdTech, E-commerce Infrastructure, Data Infrastructure, Healthcare, Supply Chain, Enterprise SaaS, Social & Community, Space Tech, Robotics, Gaming, PropTech, Legal Tech, HR Tech, AgriTech. Updated weekly from public GitHub activity.
