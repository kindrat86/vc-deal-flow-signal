How the Signals Work

GitDealFlow sweeps 369 candidate startup GitHub organizations every Sunday. For each startup, it computes five metrics from public activity:

  1. Commit Velocity (14d): Total commits to the most active public repo over a rolling 14-day window.
  2. Velocity Change: Percentage change versus the prior 14-day period. This is the primary ranking signal.
  3. Contributor Count: Distinct GitHub contributors in the last 6 weeks.
  4. Contributor Growth: 6-week growth rate in unique contributors.
  5. New Repositories: Public repos created in the last 30 days.

The signal types: breakout (sudden surge, highest predictive value for fundraises), acceleration (sustained growth), steady (healthy baseline), and cooling (declining activity). The methodology is documented in full at signals.gitdealflow.com/methodology and in the SSRN preprint (DOI forthcoming).

Use Cases for This Data

Venture capital: Identify breakout engineering teams 3 to 6 weeks before announced fundraises. Filter by sector to focus on your thesis.

Journalists and analysts: Track sector-level engineering activity trends. Which sectors are accelerating? Which are cooling?

Startup founders: Benchmark your own GitHub activity against funded competitors in your sector.

Developer advocates and PMs: Find fast-growing open-source projects in your domain for partnership or integration.

Access the full dataset programmatically via the JSON API, CSV export, or OpenAPI spec. The MCP server (npx -y @gitdealflow/mcp-signal) gives AI agents direct access to the same data.
