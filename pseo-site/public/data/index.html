Data Access

All datasets are available as downloadable CSV and JSON files. For programmatic access, use our free API endpoints:

  • JSON API: GET https://signals.gitdealflow.com/api/signals.json
  • CSV Export: GET https://signals.gitdealflow.com/api/signals.csv
  • MCP Server: npx -y @gitdealflow/mcp-signal
  • A2A Endpoint: POST https://signals.gitdealflow.com/api/a2a
