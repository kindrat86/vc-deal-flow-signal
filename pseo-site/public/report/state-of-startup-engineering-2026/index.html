Methodology

Data is sourced from the public GitHub REST API across ~4,200 candidate startup GitHub organizations. We measure commit velocity over a rolling 14-day window, contributor counts, new repository creation (30-day), and compound signal types. The dataset refreshes weekly on Mondays ~09:00 UTC.
