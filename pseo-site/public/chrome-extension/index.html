How to Install

  1. Clone the repo: git clone https://github.com/kindrat86/gitdealflow-signal-classifier.git
  2. Open Chrome: Navigate to chrome://extensions
  3. Enable Developer Mode (toggle top-right)
  4. Load unpacked: Click "Load unpacked" and select the chrome-extension/ folder
  5. Browse Crunchbase or Wellfound — badges appear automatically
🔒 Permissions Required
Host accessCrunchbase + Wellfound + signals.gitdealflow.com
StorageLocal cache of signal data (no user data collected)

No tracking, no analytics, no ads. All data fetched from the public API at signals.gitdealflow.com.

FAQ

Does this work on every Crunchbase page?
Yes — it activates automatically on any crunchbase.com/organization/* page. If the startup is in our dataset (324+ companies), the badge appears within 1-2 seconds.
Does it collect my data?
No. The extension only reads the company URL from the page, fetches public signal data from our API, and displays a badge. No analytics, no tracking, no data sent anywhere else.
How fresh is the data?
Data refreshes every Monday. The badge shows the week of the data so you know how current it is.
Can I contribute?
Yes! The extension is open source. PRs welcome on GitHub. We'd love support for other platforms like PitchBook, LinkedIn, or AngelList.
